## Remaining boundaries

No unresolved defect from the scoped regressions remains. This does **not** close Linux portability: the recorded default-container attempt executed no assertion because Chromium lacked a usable sandbox. The original namespace policy was subsequently approved and applied to the current-build attempt described in [LINUX-REPLAY](LINUX-REPLAY.md). Both assertions remained unrun; a separate, additional chroot proposal remains unexecuted pending specific approval. Native 200% zoom remains a separate unverified UI gate.

The local workspace is trusted; file checks are not a race-proof hostile-filesystem sandbox. The loopback token protects browser-origin mutations, not against another process acting as the local user. Native CPU/memory/process isolation, arbitrary workers/native integrations, huge-output hostile processes and public/untrusted execution are unsupported. The earlier ledger-only recovery did not exercise a live browser; the continuation tests below do. Neither establishes universal cleanup after arbitrary process/host failures. Export hashes establish integrity; excluded installed dependencies are not attested. Privacy relies on synthetic data and allowlists, not an exhaustive personal-data scanner; caller-defined identifiers must remain synthetic. These limits and the remaining release gates must remain visible in [RELEASE](RELEASE.md).
