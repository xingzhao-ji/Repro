# Included assets and dependencies

The starter code, SVG assets, CSS, prototype and documentation in this kit were generated for this project. They do not incorporate copied commercial screenshots, paid fonts, production datasets or vendor binaries.

Referenced tools and publications retain their own licenses and terms. Before vendoring a dependency or historical application fixture, inspect its actual license and record attribution. The implementation agent must not infer redistribution permission from a public GitHub URL.

Choose an appropriate project license with the owner before public release. This kit does not create a public repository, agree to a vendor contract, or publish anyone's personal information.
