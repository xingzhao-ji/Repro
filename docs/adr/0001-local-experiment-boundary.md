# ADR 0001 — Registered local experiment boundary

Status: implemented for local development; release gates are tracked separately.

Repro starts with one registered synthetic frontend adapter. The original kit's `search-stale-response` model and oracle remain training assets. The product's `browser-search` fixture executes actual fetch requests from a browser form. Its buggy and fixed JavaScript differ at the stale-response guard. The runner releases the beta response before alpha and observes the DOM after both completions. The API response substitute is outside the frontend behavior under test; this experiment makes no backend-fix claim.

The frozen assertion retains the supplied specification's SHA-256 identity. `expectationBasis` is `supplied-synthetic-specification`; `humanApproval` is `not-claimed`. An agent-proposed unconfirmed expectation returns INCONCLUSIVE. The Node assertion executes outside the candidate page; the candidate has no Node bindings for filesystem or harness changes. Only known fixture source digests execute locally. Unknown imported code, arbitrary URLs, authentication, databases and native/browser features beyond this fixture are unsupported. This is a trusted local development boundary, not a hostile-code service.

`record --consent` captures an explicitly scripted synthetic browser session. It records actual trusted input/submit events, requests, response completion and assertion evidence. It does not record an existing browser profile or arbitrary manual browsing. Initial storage is empty. Date, seed, locale, timezone, viewport, inputs and response order are explicit. The fixture does not use timers, performance time, workers or cryptographic randomness; these are not claimed controlled for arbitrary apps. Every replay launches a fresh owned browser and HTTP service. PostgreSQL is unnecessary for this fixture and remains unsupported pending its own adapter and reset tests.

TypeScript strict mode, React, Playwright, Node's HTTP server and SQLite have concrete roles. A single package keeps these boundaries in separate modules without creating independent publishable packages prematurely. SQLite persists sessions, jobs, monotonically sequenced events and exact results. Its owner lock prevents a second live coordinator from falsely recovering active jobs. Restart converts unfinished jobs to interrupted/INCONCLUSIVE. Request keys deduplicate retries; one job per session runs at a time. Cancellation reaches only that job's controller and browser.

Action reduction deletes chunks and prerequisite-dependent groups. Every accepted candidate meets the same repeated target-failure criterion and independently checks the observed value, input, source and harness identities. There is no cross-run cache. Budgets count baseline, repetition and rejected trials. Final neighbor checks refer to the final candidate. Inconclusive neighbors leave minimality unverified; no global minimum is claimed. State and fixture reduction await adapter constraints and reset evidence.

Capsules are bounded allowlisted directories, with conventional Node tests and a locked dependency recipe. Archives are rejected rather than unpacked. Export stages, validates and renames an owned temporary directory; interruption cannot make a partial directory importable. Schema, runner, adapter, source, assertion and every artifact are checked before replay. Imported executables are compared with the installed trusted runner, rather than trusted solely because their manifest hashes match. Exact build changes invalidate earlier exports even when the semantic version is unchanged. A future release migration needs an explicit compatibility policy.

Linux containers are the portability target. Local macOS browser evidence is recorded separately. Browser and package acquisition use official sources; replay has no public service dependency. A fresh isolated container must establish actual portability before that gate is marked passed. Container resource/network boundaries and browser sandbox results must be reported as observed, never inferred from a Dockerfile.

Alternatives deferred: generic adapter plugins executing arbitrary host code; raw browser recording; automatic assertion synthesis/approval; opaque archives; distributed workers; hosted storage; LLM-dependent execution. Each would expand a boundary without improving the first supported reproduction.
